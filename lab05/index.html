University of Baltimore - Simulation and Game Design Webpage

1. What is the URL of the website?

University of Baltimore - Simulation and Game Design

2. What is the name of the website?

The name of the website is University of Baltimore - Simulation and Game Design (B.S.).

3. Who is the site's target audience?

The target audience are students who are interested in studying game design, programming, animation, and game development.

4. How is the site organized?

The website uses a hierarchical structure. It has main menus and smaller sections that help users find information about academic programs, admissions, and degree requirements.

5. Which CRAP Design Principle does the site use?

The website uses the repetition principle. For example, it uses consistent headings and design elements throughout the page, making the information look organized.

6. What is the Accessibility Audit Score?

The website received an accessibility score of 78 out of 100. The Accessibility Checker marked the website as not compliant because it found accessibility issues that need improvement.

Accessibility Audit Screenshot

7. What is the site's effectiveness?

The website is effective because it provides information about the game design program, degree requirements, and career opportunities. It also has links that help students find admissions information and apply.

8. What is the site's efficiency?

The website is decently efficient because it has menus and quick links that help users find important information. However, some information requires scrolling through a long page.

9. How is the site's engagement?

The website is engaging because it uses pictures, videos, and information about game design. These features make the page more interesting for students who want to learn about the program.

10. What would you recommend improving?

I would recommend improving the website's user experience by adding something like demos or less paragraphs.
